## About my project

This is my first 6 layer complex pcb it help people by showing voltage and when drop some amount voltage then led light,buzzer on this is a warning feature and have green light to indicate the voltage was ok.And you also see on smart phone,tablet while via connect with esp 32 wifi.

## How it work

Some smd component send a number but some components not send anything this number convert into resistance or voltage to see this components ok or not and also show on the display and  also have led and buzzer.This is  full process of my project.
